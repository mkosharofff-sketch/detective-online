# Дело // Online

Однофайловая браузерная детективная игра для Discord на Firebase Realtime Database.

## Уже работает

- Создание комнаты ведущим и вход по шестизначному коду.
- Роли: ведущий, один детектив, игроки-персонажи.
- Редактор дела, персонажей, секретов, целей и истины.
- Назначение персонажей игрокам с приватными карточками.
- Старт расследования, вызов и завершение допросов.
- Ручная выдача фактов, личные заметки детектива.
- Одно финальное обвинение и публикация развязки.
- Адаптивный интерфейс для телефона и компьютера.

## Обязательная настройка Firebase

1. В Firebase Console включите Authentication → Sign-in method → Anonymous.
2. Откройте Realtime Database → Rules.
3. Вставьте содержимое `database.rules.json` и нажмите Publish.
4. GitHub Pages публикует `index.html` из корня ветки `main`.

> Важно: Firebase Rules не разворачиваются через GitHub Pages. Их нужно опубликовать в Firebase Console вручную либо подключить Firebase CLI.
